# Сценарій навантажувального тестування

## Запуск тесту
Тест імітує read-heavy навантаження: кожен користувач робить 1 операцію запису (POST) та 9 операцій читання (GET).
Команда для запуску:
```bash
LOADTEST_MAX_USERS=200 locust -f loadtest/locustfile.py --host=https://api.auto-catalog.app --csv=results/loadtest --html=results/loadtest.html
```

## Параметри профілю
- **Фаза наростання (Ramp-up):** від 0 до 200 користувачів за 150 секунд (2.5 хв).
- **Стале навантаження (Hold):** 200 користувачів протягом 300 секунд (5 хв).
- **Спад (Ramp-down):** від 200 до 0 користувачів за 120 секунд (2 хв).

## Підсумковий звіт
- **Загальна кількість запитів:** ~63 407
- **RPS на плато:** ~105.7 (до масштабування), ~200 (після масштабування)
- **Частка помилок (Failures):** 0%
- **Латентність (Aggregated):**
  - p50 (медіана): 310 ms
  - p95: 1200 ms
  - p99: 1800 ms
*(Примітка: ці затримки включають час до спрацювання автомасштабування; після старту другого контейнера і включення кешу затримка впала до ~40 ms).*
